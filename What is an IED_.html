What is an IED?

Intelligent Electronic Device

An IED is a small computer built into the power grid. It measures current and voltage, decides if something is wrong, and acts by opening a circuit breaker.

How it works

Measure→ Detect fault→ Trip breaker→ Report

Why it matters

  • It protects transformers, lines, and motors from damage.
  • It isolates a fault in milliseconds, so the rest of the grid keeps running.
  • It talks to other devices and control rooms (SCADA).

Common protection functions

ANSI 50/51
Overcurrent: trips when current is too high.
ANSI 27
Undervoltage: trips when voltage drops too low.

How IEDs communicate

IEC 61850 is the international standard for substation communication. GOOSE sends fast trip signals between devices. Sampled Values stream measurements.

Our project: vIED

Today an IED is a dedicated hardware box. vIED asks: can the same functions run as software on standard Linux, for substations that cannot afford heavy equipment investment?
